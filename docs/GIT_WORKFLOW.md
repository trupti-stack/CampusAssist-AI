\# CampusAssist AI – Git Workflow



The project uses Git for version control.



The main branch contains the integrated application.



A separate feature branch named

feature/submission-evidence is used to

prepare and maintain submission documentation.



The workflow follows these steps:



1\. Create a feature branch from main.

2\. Make the required project changes.

3\. Stage the changed files.

4\. Commit changes with meaningful messages.

5\. Switch back to main.

6\. Merge the feature branch.

7\. Verify the commit history.



This workflow keeps changes organized and

allows project updates to be reviewed before merging.
